# Security and privacy boundaries

Agent Ops Clinic is a **simulation** for teaching safe agent governance, not a certified security system or production sandbox.

- No server-side processing or outbound API calls are required.
- Scenario data is fictional and browser-local.
- Browser storage may persist demo state locally; use Reset to clear the app's local state.
- Exports are downloaded to the user's own device; do not upload real private data to public issues.
- A simulated gate illustrates an engineering pattern; it is **not** a full production policy engine, authorization mechanism, secrets scanner, or complete audit system.
- Do not deploy this directly as a real customer workflow without independent threat modeling, authentication, access controls, backend validation, observability and security review.

Please open an issue with a minimal synthetic reproduction for non-sensitive flaws. Avoid publishing live credentials or exploit details containing private customer information.
